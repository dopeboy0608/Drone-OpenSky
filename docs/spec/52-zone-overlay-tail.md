# 스펙: 구역 안내 박스 클릭 위치 꼬리 (#52)

## 배경/목적

구역을 클릭/터치하면 뜨는 안내 박스(`AirspaceZoneOverlay`)가 클릭 지점 위로 떠 있고(`yAnchor={1.4}`)
지점을 가리키는 표시가 없어, 정확히 어디를 눌렀는지 알 수 없다. 마커의 핀 끝처럼 꼬리 끝이 클릭
좌표를 가리키게 한다.

## 입력

- **`position`**: 클릭 좌표(`AirspacePolygon`의 `mouseEvent.latLng`). 변경 없음.
- **`zoneType`, `onClose`**: 변경 없음.

## 기대 동작

- [ ] 박스 아래 중앙에 아래를 향한 꼬리가 붙고, 꼬리 끝이 `position`(클릭 좌표)에 정확히 놓인다.
- [ ] 제목 표시, 닫기 버튼, 필터로 숨김 시 닫힘 동작은 그대로다.
- [ ] 박스 아래가 지도 클릭 이벤트를 가로채지 않는다(꼬리 영역 포함, 기존과 동일하게 박스만 반응).

## 엣지케이스

- [ ] 제목이 긴 구역 종류(예: `초경량비행장치공역(UA)`)여도 꼬리가 박스 중앙에 있다.
- [ ] 지도 가장자리 근처 클릭에서도 꼬리 끝이 클릭 지점과 어긋나지 않는다(`yAnchor` 기준이 바뀌지 않음).

## 범위 밖

- 박스 내용 확장(주소, 비행 가능 여부는 #27), WMS 모드 클릭 안내(#75), 클릭 지점 마커 추가.
- 순수 로직이 없는 CSS 변경이라 자동 테스트 대신 화면 확인 시나리오로 검증한다(`MapView.test`는 오버레이를 모킹함).
