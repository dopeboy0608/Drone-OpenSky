# 스펙: 클릭 시 비행승인 안내 (주소 + 비행 구역 여부)

## 배경/목적

지도를 클릭하면 해당 위치의 **주소**와 **적용되는 최우선 구역 기준 안내**를 기존 안내 박스(`AirspaceZoneOverlay`)에 보여 준다 (참고: `docs/draft/drone_onestop_reference.md` 4번). 사용자가 2026-11-11 이슈 댓글에서 확정한 결정을 따른다.

## 확정된 결정

- 판정은 구역 **레벨**(금지/제한/가능)에 따른 안내까지만 한다. "승인 불필요" 같은 도메인(법적) 판단은 하지 않고, 국토부 타일 검증 이슈(#76)와 함께 고도화한다.
- 중첩 구역은 **최상위(우선순위가 가장 높은) 하나만** 안내한다. 겹침 확인은 범례 필터로 한다.
- 구역이 없거나 조회가 실패해도 "비행 가능"으로 단정하지 않는다. 일부 조회 실패는 판정 없이 오류 안내한다(기존 `findZoneTypeAtPoint`의 throw 유지).
- 주소는 도로명 우선 + 지번 병기, 주소가 없는 곳은 행정구역만 보여 준다.
- UI는 기존 오버레이 카드를 확장한다. 주소 조회는 판정과 병렬이며 실패해도 판정에 영향을 주지 않는다.

## 변경된 결정 (2026-11-12, 후속)

- 클릭 구역 판정은 표시 방식과 무관하게 **좌표 기준 점 WFS 조회**로 통일한다. 폴리곤 클릭도 폴리곤의 종류가 아니라 클릭 좌표로 같은 조회를 한다(같은 레벨 안에서는 맨 위에 그려진 폴리곤이 클릭을 받아 우선순위와 어긋났다). 지도 클릭이 폴리곤 위에서도 함께 오는지는 브라우저 확인 전이라, 폴리곤의 클릭과 지도 클릭이 모두 같은 조회를 호출하고 마지막 요청만 반영한다(중복 호출은 앞선 것을 취소).
- 조회 대상은 범례 필터와 무관하게 12개 전부다. 숨긴 구역이 걸리면 카드에 "범례에서 숨긴 구역입니다."를 표시하고, 범례를 꺼도 열린 안내를 닫지 않는다. (이전 결정 "중첩은 범례 필터로 처리"를 대체)
- 겹침 표시: 최상위 구역을 확정되는 즉시 먼저 띄우고, 겹친 구역은 도착하는 대로 "겹침: A, B" 줄에 덧붙인다(`findZonesAtPoint`의 `onProgress`). 줄은 확인 중에도 자리를 차지해 카드 높이가 변하지 않는다. 확인이 끝나기 전에는 "없음"으로 단정하지 않으며, 일부 조회가 실패하면 그 사실을 밝힌다. 최상위가 없고 일부가 실패하면 기존대로 오류 안내한다.
- 한 번의 클릭에서 폴리곤 클릭과 지도 클릭이 모두 오면 300ms·약 1m 안의 연속 호출을 하나로 합친다(조회 24건 → 12건).
- 안내 카드는 `clickable`로 열어 카드·닫기 버튼을 눌러도 지도 클릭이 발생하지 않게 한다.

## 입력

- 선택된 구역: `SelectedZone { position, zoneType: string | null }` (`null` = 조회 결과 구역 없음)
- 클릭 좌표 → 카카오 `Geocoder.coord2Address`, 주소가 없으면 `coord2RegionCode`

## 기대 동작

- [ ] 구역 라벨 → 레벨(`prohibited`/`restricted`/`available`)을 찾는 순수 함수와 안내 문구 함수(`resolveFlightGuidance`)를 둔다.
  - 금지: 비행 금지 구역, 비행 전 승인 절차 확인 안내
  - 제한: 비행 제한 구역, 승인 필요 여부 확인 안내
  - 가능(UA·시범사업): 비행 가능 공역으로 분류되나 승인 필요 여부는 공식 확인 필요
  - 없음: "조회된 규제 구역 없음" + 참고용이며 비행 전 공식 확인 필요
- [ ] WMS 모드에서 클릭 지점에 구역이 없으면 안내를 닫지 않고 "구역 없음" 안내를 띄운다.
- [ ] 안내 카드에 주소를 보여 준다: 조회 중 / 도로명(+지번) / 행정구역 / 찾지 못함 / 조회 실패.
- [ ] 폴리곤 모드의 구역 클릭에도 같은 카드(주소 포함)를 쓴다.

## 엣지케이스

- [ ] 도로명 주소가 없으면 지번 주소만, 둘 다 없으면 행정구역(`coord2RegionCode`), 그것도 없으면 "찾지 못함".
- [ ] 주소 조회가 실패해도 구역 안내는 그대로 표시한다.
- [ ] 새 클릭으로 위치가 바뀌면 이전 주소 응답이 늦게 도착해도 덮어쓰지 않는다.
- [ ] 알 수 없는 라벨은 레벨을 단정하지 않고 구역명만 보여 준다.

## 범위 밖

- 연락처·비고 문구(이슈 본문), "승인 불필요" 판정(#76과 함께).
- 폴리곤 모드에서 빈 땅을 클릭했을 때의 "구역 없음" 안내: Polygon 클릭 시 카카오 지도 클릭 이벤트가 함께 발생하는지 브라우저에서 확인되지 않아 이번 범위에서 제외한다(WMS 모드는 좌표 기반이라 해당 없음).
