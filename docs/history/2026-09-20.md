  - "💻 개발 공부" 페이지 하위에 "서버리스 relay로 CORS 우회하기: Cloudflare Workers vs Vercel" 스터디 노트 신규 작성 (https://app.notion.com/p/3e172a17ef698192988cf400e62184d7) — CORS 본질, Cloudflare가 안 된 이유(리전 고정 불가), Vercel 리전 고정으로 해결, 요청/응답 헤더 혼동 포인트, VWorld 검증 허점, 실전 버그 2건(ESM/CJS, 동시성), Vercel 기능/비용 지형도 정리.
