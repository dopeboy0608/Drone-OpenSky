# 드론 원스톱 "비행 계획 / 비행가능 지역 검색" 지도 기능 정리

- 페이지: [drone.onestop.go.kr/common/flightArea](https://drone.onestop.go.kr/common/flightArea)
- 성격: 국토교통부 드론 원스톱 민원서비스에서 제공하는 지도 기반 비행가능구역 조회 도구

## 1. 지도 표시 기능

전국 지도 위에 각종 항공 규제구역을 색상과 패턴으로 구분하여 표시하며, R101~R156 등 구역번호도 함께 나타납니다. 표시되는 구역 종류는 다음과 같습니다.

- 비행금지구역
- 비행제한구역
- 관제권
- 경계구역
- 비행장교통구역
- 경량항공기 이착륙장
- 위험지역
- 드론시범사업구역
- 장애물공역
- 사전협의구역
- 임시비행금지구역
- 문화재보호구역
- 국립자연공원
- 초경량비행장치공역(UA)

## 2. 범례(레이어 제어)

좌측 하단 **"범례"** 버튼을 누르면 위 구역 항목들이 체크박스 목록으로 나타나며, 항목별로 지도에 표시할지 여부를 개별적으로 켜고 끌 수 있습니다. **"전체 해제"** 버튼으로 모든 레이어를 한 번에 끌 수도 있습니다.

## 3. 주소검색

**"주소검색"** 버튼을 통해 특정 주소를 입력하면 해당 위치로 지도가 이동합니다. 원하는 장소가 비행가능구역인지 바로 확인할 수 있습니다.

## 4. 위치 클릭 시 비행승인 안내

지도상의 특정 지점을 클릭하면 해당 위치에서 드론 비행승인이 필요한지 여부를 알려주는 안내 팝업이 표시됩니다. 이와 함께 우측의 정보 표에 다음 항목이 채워집니다.

| 항목 | 내용 |
|---|---|
| 주소 | 클릭한 위치의 주소 |
| 비행구역 담당자 | 해당 구역 관련 담당 연락처 |
| 특별비행 담당자 | 특별비행 관련 담당 연락처 |
| 항공촬영 담당자 | 항공촬영 관련 담당 연락처 |
| 비고 | 사유지, 해수욕장, 국립공원, 문화재, 청와대, 교도소, 군부대, 국가중요시설, 항만 등은 소유자·관리사무소와 반드시 사전 협의하라는 안내 문구 |

## 5. 배경지도 전환

우측 상단의 레이어 아이콘을 누르면 배경지도를 다음 두 가지 중에서 전환할 수 있습니다.

- VWorld Map (일반 지도)
- VWorld Map Satellite (위성 지도)

## 6. 확대/축소

좌측 상단의 **+ / −** 버튼으로 지도를 확대·축소할 수 있습니다.

## 7. 항공고시보(NOTAM) 연동

**"항공고시보"** 버튼을 누르면 한국항공정보포털시스템(aim.koca.go.kr)의 NOTAM 페이지가 새 탭으로 열려, 실시간 항공고시보 정보를 확인할 수 있습니다.

---

**요약**: 이 지도는 드론을 띄우기 전에 원하는 위치가 비행가능구역인지, 어떤 규제(비행금지·제한구역 등)가 적용되는지, 사전 승인이나 협의가 필요한지를 확인하고 관련 담당 기관 연락처와 최신 항공고시보까지 한 번에 확인할 수 있도록 돕는 조회 도구입니다.
