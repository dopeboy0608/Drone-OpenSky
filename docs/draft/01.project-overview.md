# 01. 프로젝트 개요

# README.md

- 프로젝트 개요: Drone OpenSky는 드론 비행 가능/제한/불가 구역을 실시간 지도 기반으로 제공하는 서비스
- 주요 기능:
    - 공공 API 연동 (국토교통부, 브이월드 등)
    - Kakao Map 기반 폴리곤 오버레이
    - 필터 기능으로 구역별 표시 제어
    - 향후 커뮤니티 기능(유저 메모/팁 마커) 확장 예정
- 기술 스택: React, Kakao Map API, GeoJSON 데이터 변환
- 실행 방법: 설치, 환경변수(API Key), 로컬 실행

---

## ARCHITECTURE.md

- 구조 개요:
    - React 컴포넌트: Map, PolygonLayer, FilterPanel

## 2026-09-11 결정사항 (grill-me 세션)

이 초안은 원본 그대로 보존하고, 실제 반영 결정만 아래에 기록한다.

- 문서 세트는 초기에는 `README.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `CLAUDE.md` 4개만 작성. `API_REFERENCE.md`는 데이터 소스 확정 후 별도 작성. `CONTRIBUTING/CODE_OF_CONDUCT/SECURITY/CHANGELOG`는 협업자/배포 단계 진입 시 추가.
- 문서 위치는 리포지토리 루트 (`docs/` 하위 분류는 문서가 늘어나면 그때 도입).
- 기술 스택 확정: rsbuild + React + TypeScript, pnpm, Tailwind CSS + Ant Design, zustand, TanStack Router, axios + TanStack Query 혼용 (캐싱/재시도 필요 시 TanStack Query, 단발성 조회는 axios 직접 사용).
- Kakao Map 사용 확정.
- 공공 API 데이터 소스 조사 결과 VWorld(브이월드) WFS API로 확정 (GeoJSON 직접 반환, 좌표계 선택 가능). 국토교통부 API(data.go.kr), 항공정보도 WMS/WFS는 2단계 이후 보조 소스로 보류. 상세는 `API_REFERENCE.md` 참고.
- ARCHITECTURE.md에 DB/OAuth/AI 추천 등은 "Out of scope (future)" 섹션으로만 짧게 언급.
